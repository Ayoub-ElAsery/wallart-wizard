## 1. Why does this repository qualify?

WallArt Wizard fills a real gap in open-source design automation. Print-on-demand sellers currently rely on expensive, manual Photoshop workflows to resize artwork to dozens of standard print sizes at 300 DPI. This tool automates that entire pipeline — parallel processing, smart quality scoring, batch ZIP exports — in a free Python/Streamlit app. It directly benefits a large, underserved creator community and sets the foundation for an open ecosystem of AI-powered creator tools.

## 2. How will you use API credits for your project?

We plan to integrate the OpenAI Vision API to add intelligent image analysis: auto-detecting subject position for smarter cropping (avoiding cut-off faces/text), recommending the optimal aspect ratios per image, and generating SEO-optimized titles and tags for each resized artwork. This turns WallArt Wizard from a resizer into an AI-powered listing assistant — directly helping sellers publish faster and sell more.

## 3. Anything else we should know?

WallArt Wizard is built with Python and Streamlit, making it easy for contributors of any skill level to jump in. Our roadmap includes AI-driven auto-cropping, mockup generation, and metadata tagging — all backed by OpenAI APIs. We're committed to building a welcoming open-source community around creator tools and plan to actively recruit contributors from the print-on-demand and digital art communities.
